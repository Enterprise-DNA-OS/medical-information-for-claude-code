# Selection and sources

Checked 20 October 2026. The registry had no queued build. Technical publications and visitor management were already built tonight. Medical-information administration is a new registry family, distinct from trial-site operations and provider credentialing.

## Candidate comparison

Scores in order: annual bill, data-shaped, buyer evidence, search demand, session buildability, import path.

| Candidate | Scores | Decision |
|---|---|---|
| Salesforce Life Sciences Cloud medical-information desk | 5, 5, 1, 2, 4, 4 = 21 | Selected; public licensing makes the annual scenario verifiable |
| IntelligenceBank marketing compliance | 1, 4, 2, 2, 4, 3 = 16 | Held; compliance price is private, so no evidenced five-figure bill this run |
| Chemwatch chemical register | 1, 4, 3, 2, 3, 3 = 16 | Held; no verified target bill and its maintained safety-document library is outside a simple rebuild |

Scoring is judgment, not measured market research. Buyer evidence is low: no current customer adoption or actual invoice was established. Search demand was not measured. Local customer documents produced no matching adoption evidence. No live customer system was queried.

The modeled annual scenario is US$150,000 for 25 licensed users: 25 times 12 times Core US$350 plus Customer Engagement US$150 per user per month. This is not a claimed real business invoice, price quote or expected saving. The scoped free desk does not replace the entire suite.

## Primary sources

- [Current Salesforce pricing](https://www.salesforce.com/life-sciences/cloud/pricing/): Core US$350 per user/month, annual billing; Customer Engagement US$150 per user/month. The current web page takes precedence over older edition names and figures in downloadable PDFs.
- [Medical Inquiries](https://help.salesforce.com/s/articleView?id=ind.lsc_medical_inquiries_intro.htm&language=en_US&type=5): request capture, routing and response workflows; Customer Engagement licensing requirements.
- [Report export](https://help.salesforce.com/s/articleView?id=sf.reports_export.htm&language=en_US&type=5): Details Only CSV with Export Reports permission. This supports the file transport, not a universal inquiry CSV schema.
- [IntelligenceBank pricing](https://intelligencebank.com/pricing/): custom pricing for Marketing Compliance. Its base DAM price is not evidence for the compliance package.
- [Chemwatch](https://chemwatch.net/): maintained safety data is a material part of its offering.
- Compliance sources and implementation limits are in compliance.md.

The ten questions in the README are implemented queries. There is no evidence that Salesforce cannot be configured to answer them. The page makes no such claim.
